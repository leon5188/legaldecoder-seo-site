# 什么是 Default Judgment？——别以为“不出庭”就能躲过官司

作为一名天天和法院打交道的律师，我发现很多非法律专业的朋友都有一个致命的误区：“只要我不接传票、不去开庭，法院就拿我没办法。”

这种想法在法律上极其危险，它会直接触发一个让你欲哭无泪的法律后果：**Default Judgment**。

---

## 1. 什么是 Default Judgment？（一句话总结）

**Default Judgment（缺席判决）就是当有人告你时，你没在规定时间内回应或出庭，法官直接判对方“躺赢”。**

---

## 2. 大白话深度解释：法律世界的“弃权即判负”

想象一下，你参加一场拳击比赛。裁判鸣哨了，对手已经戴好手套站在台中央，而你却在家睡觉，甚至关掉手机假装不知道这回事。

裁判会取消比赛吗？**不会。**

在法律程序中，裁判（法官）会认为你已经放弃了辩解的权利。既然你不出面否认对方的指控，法官就会默认对方说的一切都是真的。

*   对方说你欠他100万？**准了！**
*   对方说你应该赔偿精神损失费？**准了！**
*   对方要求查封你的房产？**准了！**

**Default Judgment 的本质是：法律保护那些积极行使权利的人，而不保护在权利上睡觉的人。** 一旦判决书下达，它的效力和你拼命辩论后输掉的判决是一模一样的——你的银行账户会被冻结，你的工资会被划扣，你的信用记录会破产。

---

## 3. 现实生活中的生动例子

**案例：消失的租客小王**

小王退租后，房东声称小王损坏了昂贵的大理石地板，要求赔偿 2 万美元。小王觉得这是敲诈，心想：“反正我已经搬走了，你发给我的法院传票我不签收、不回应，你能把我怎么样？”

结果：
1.  房东向法院证明已经通过挂号信或者报纸公告“送达”了起诉书。
2.  小王在法定的 21 天（不同地区时限不同）内没有提交任何答辩状。
3.  房东申请 **Default Judgment**。
4.  法官在没有小王参加的情况下，直接签署了判决书。

半年后，小王发现自己买车申请贷款被拒，去银行一查，发现账户里的 2 万多美元存款已经被法院强制划走了。小王这时才醒悟：**“我不理它”并不代表“它不存在”。**

---

## 4. 合同中关于此条文的隐藏坑/风险

在签署商业合同或贷款协议时，对方律师经常会埋下几个加速 Default Judgment 进程的“地雷”：

*   **送达条款 (Service of Process Clause)：**
    合同里规定，只要把文件寄到你十年前的旧地址，就算“送达成功”。如果你搬家没通知对方，对方起诉你时，你可能根本不知道，等你知道时，缺席判决已经下来了。
*   **缩短响应时间：**
    某些合同会约定比法定更短的回复时限，让你措手不及。
*   **授权辩护/放弃通知条款 (Cognovit Note/Confession of Judgment)：**
    这是最狠的。某些州的借款合同中，你一旦签字，就等于授权对方律师在你不还钱时直接替你向法院“认罪”。这种情况下，你甚至连收到传票的机会都没有，判决就直接生效了。

---

## 5. 资深律师的避坑建议

为了不让自己莫名其妙地成为 Default Judgment 的受害者，请务必做到以下几点：

1.  **别玩“躲猫猫”：** 逃避签收法院传票是没用的。法律上有多种方式（如公告、替代送达）可以视为你已收到。躲得了一时，躲不了判决。
2.  **更新联系地址：** 无论是银行、保险公司还是合同对方，只要你搬家，一定要书面通知。别让法律文件寄到“无人区”。
3.  **哪怕是“垃圾官司”也要回应：** 有时候对方的起诉完全是胡扯，但你也要在规定时间内向法院提交一份简单的答辩状（Answer）。只要你回应了，对方就不能申请缺席判决，必须进入举证阶段。
4.  **第一时间找律师：** 收到法院文件的 24 小时内，请联系律师。很多时候，律师只要发一封信给对方，就能为你争取到更多的准备时间。
5.  **补救措施（Set Aside）：** 如果你确实因为特殊原因（比如重病、没收到通知）错过了期限，可以尝试申请“撤销缺席判决”（Motion to Set Aside Default Judgment）。但这通常需要支付额外的法律费用，且成功率并非 100%。

**总结语：**
在法律面前，沉默不是金，而是“认栽”。面对诉讼，请务必发声！
